# PABW Pertemuan 12

Proyek ini mengubah halaman P11 menjadi aplikasi Vue menggunakan Vite.

## Teknologi
- Node.js: v24.22.1
- npm: 11.19.1
- Vue
- Vite 8.3.5

## Komponen Vue
- `KepalaProfil.vue`
- `TombolFilter.vue`
- `DaftarProyek.vue`
- `FormKontak.vue`

## Fitur
- Katalog film favorit
- Form tambah film dengan validasi
- Filter daftar proyek
- Tombol favorit
- Penyimpanan preferensi menggunakan localStorage
- Pengambilan data proyek dari API
- Build produksi menggunakan Vite
